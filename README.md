# Portfolio

My portfolio website built with React + TypeScript + Vite + Tailwind CSS.

## Live Site

https://ShreyaM5.github.io/Portfolio/

## Local Development

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.

## Making Changes

1. Edit files in `src/`
2. Preview locally with `npm run dev`
3. Deploy with:

```bash
git add -A
git commit -m "your message"
git push
```

Pushing to `main` automatically builds and deploys via GitHub Actions (see `.github/workflows/deploy.yml`). The site goes live in 1-2 minutes.

## Scripts

- `npm run dev` - start dev server
- `npm run build` - build for production
- `npm run lint` - lint
- `npm run typecheck` - typecheck
- `npm run test` - run tests
